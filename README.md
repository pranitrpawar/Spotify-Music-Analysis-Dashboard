# Spotify Music Analysis Dashboard

## 📊 Project Overview
The Spotify Music Analysis Dashboard is an interactive Power BI project designed to explore music listening trends, album performance, artist popularity, and track statistics across different years and platforms.

## 🎯 Project Objectives
- Analyze albums, artists, and tracks played over time.
- Compare current-year and previous-year performance.
- Identify the top 5 albums, artists, and tracks.
- Explore listening trends across different platforms.
- Analyze shuffle and skipped-track patterns.

## 🛠️ Tools & Technologies
- Power BI
- Excel
- Data Analysis
- Data Visualization
- Business Intelligence

## 📈 Key Metrics
- **Albums Played:** 7,907
- **Artists Played:** 4,112
- **Tracks Played:** 13,665

*Note: Metrics represent the dashboard screenshot and may vary with filters.*

## 📌 Dashboard Features
- Album, Artist, and Track Analysis
- Yearly Trend Analysis
- Current Year vs Previous Year Comparison
- Top 5 Albums, Artists, and Tracks
- Listening Platform Filters
- Shuffle and Skipped-Track Filters
- Interactive Visualizations

## 💡 Key Insights
- Track listening activity across multiple years.
- Identify frequently played albums and artists.
- Compare listening performance between years.
- Explore music listening behavior across platforms.

## 🚀 Conclusion
This project demonstrates practical skills in Power BI dashboard development, data visualization, KPI analysis, and music listening behavior analysis.
